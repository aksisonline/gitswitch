# gitswitch for VS Code

Status bar widget for [gitswitch](https://github.com/aksisonline/git-switcher) — see and switch your active git identity without leaving the editor.

## Requires

The `gitswitch` CLI on your `PATH` (or set `gitswitch.binaryPath` in settings).

## Features

- Status bar shows the active profile nickname (and whether it's pinned/session/global).
- Click it, or run **gitswitch: Switch Profile**, to pick a different identity via Quick Pick.
- **gitswitch: Pin Profile to This Repo** / **gitswitch: Unpin This Repo** — pin an identity to the open workspace's local git config.
